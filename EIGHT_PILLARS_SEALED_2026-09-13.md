# SVCT EIGHT PILLARS — SEALED

Re-verified 2026-09-13 from Notion eight-pillars-pattern-map-2026-09-10 + GitHub share bundle + Drive knowledge base.

1. content
2. context
3. data
4. time
5. validation (added 2026-08-05)
6. provenance
7. integrity
8. custody

Permanent SVCTs: sealed on token/cell, validation pillar required, never pruned.
Temporary/gel SVCTs: context shells, appendable, bloom new cells without dropping O-L-S.

Pattern: content+context+data+time = BIND; validation proves bind; provenance+integrity+custody = lineage.
