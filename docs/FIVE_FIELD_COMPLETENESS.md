## The five fields

1. FACE — one sentence: what it is.
2. STATUS — EARNED / ASSERTED / ESTIMATE / OPEN / HOLD / SUPERSEDED.
3. SOURCE — file, date, post id, or this session.
4. BOUND — SpaceX.
5. NEXT — one cheap act, or parked.

Missing any field = not complete. Label it. Do not decorate.
